# M21 · Кинорит — поведение в движении

Статус: кандидат реализации; публичная приёмка и финальные снимки ещё выполняются.
Предыдущая M20 остаётся историей, не доказательством готовности M21.

По явному запросу пользователя заменены имя Яснослед, оптические спирали и
карточная композиция. Новое имя — Кинорит / Kinorit. Вход объединяет крупный
вопрос, один гостевой CTA, панорамную сцену и сгенерированный фон. Главная,
Анализ и воронки в дашбордах используют общую визуализацию действительных
агрегатов: ширина потока — доля от первого этапа, тёплая ветвь — отток.
Пульсация означает направление, не новые события и не отдельных людей.

На входе явно обозначен фиксированный синтетический пример; его числа передаются
из существующего GUEST_DATASET. Переключение активации/подписки показывает два
заданных примера. После входа реальные PostgreSQL-запросы, URL-контракт, сохранение,
экспорт и серверная авторизация остаются прежними. Главная сохраняет отдельные
знаменатели: 28/56 активация и 21/28 возвращение; геометрия использует 56→28→21.

Изменены: login, shell/metadata/brand, Home/ProductFlow, Explore/FunnelTrace,
DashboardWidget и его поверхность, пустое состояние Experience, общие токены,
адаптация и переходы. Audiences/Live сохраняют таблицы, реальные timestamps и
пустые состояния в общей новой системе. Старый OpticalScene удалён из кода;
архивные M20 assets сохранены для происхождения и старых материалов.

Новых runtime-зависимостей, шрифтов, SQL, миграций, провайдеров или платных ресурсов
нет. Сохранены права, учётные записи, данные, контракты токенов и лимиты гостей.
Локальная проверка использует новую task-owned БД signal_m21_test_acceptance
на существующем task-owned PostgreSQL, порт приложения 32245. Все 37 миграций,
повторный migrate, bootstrap и два seed выполнены. Другие проекты не затронуты.

Первый visual-прогон выявил контраст заголовка пути на Главной: локальный тёмный
контекст исправлен и проверен. После удаления старого декоративного SVG проверка
движения привязана к настоящему data-flow-pulse, а не последнему случайному path.
Новые unit-тесты проверяют пропорции 336→252→168 / 336→252→84 / 56→28→21,
точный выбор исходной строки для исследования, отсутствие вымышленных частиц
при нулевых результатах и ограничение SVG-работы при восьми этапах.

Все циклические эффекты учитывают пользовательскую паузу, reduced motion, скрытую
вкладку и выход сцены за viewport. Переходы не блокируют действия; текст и таблицы
остаются доступными. Число линий ограничено, нет React state updates на каждом кадре.

## Ограничения

Автоматический Chrome/axe не заменяет ручную проверку физических телефонов,
Safari и screen reader. Не заявляются физический HDR, 1M-event performance,
ClickHouse parity или юридическая уникальность имени. Прежнее наблюдение холодной
Главной 8–9 с остаётся performance follow-up: аналитические сервисы не менялись.
Синтетический источник не содержит настоящих replay и текущей активности.
