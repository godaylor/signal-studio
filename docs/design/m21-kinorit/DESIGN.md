# M21 · Кинорит / Kinorit

Audience: PLG teams exploring activation, adoption and retention. The first screen
should make the product's actual job visible: follow people from an event to an
outcome, see where they leave, open the underlying evidence.

## Direction: behavior in motion

The signature is a panoramic flow through event gates. Gate values and stream
thickness come from analytical results. Fine moving traces show direction, never
pretend to be new events or individual tracked people. Drop-off has a warm accent,
separate labels and actual counts. Empty/unavailable results do not draw fake data.
The landing example is explicitly a fixed synthetic example; authentication and
working PostgreSQL analysis remain inside the private guest workspace.

Palette: midnight #061b2c, blue slate #15394d, mist #f0f6f8, turquoise #35e0cf,
cobalt #4478f5, apricot #ffb381. Light UI keeps a deep data stage against a calm
continuous workspace; dark UI uses the same geometry. Existing licensed Golos
Text is the primary face, Unbounded is reserved for short display text, tabular
Golos for values. No new font or runtime dependency.

Layout: continuous navigation, query lineage, a large analytical scene, then
equivalent data and evidence. One primary action per local task. Quiet text
actions share a toolbar; no decorative cards around every paragraph or number.

Entry: heading + guest action and a full-width flow converge into one composition.
Mobile stacks the introduction above a genuinely resized scene; product results
remain before complex editing. No clipping text to conceal layout defects.

Motion: coordinated scene reveal, path pulses, gate response to hover/focus,
result geometry interpolation and page sweep. User pause, OS reduced motion and
hidden-tab suspension control ambient motion. No flashing or forced waiting.

## Critique before implementation

Rejected: generic dark SaaS card grid, random glowing blobs, optical spirals,
large decorative KPI unrelated to the question, and fake live counters. The
generated reference's invented drop-off reasons, marketing promises, extra nav
and mountain interpretation are not product requirements or analytical evidence.

Name: preliminary exact Cyrillic and English searches on 2026-10-17 did not find
a matching analytics product for Кинорит / Kinorit. This is not trademark clearance.
Kinevra was rejected because https://kinevra.com/ is already a business-data product.
Design reading: https://linear.app/now/behind-the-latest-design-refresh and
https://university.mixpanel.com/student/activity/3411702-flows-understand-users-most-frequent-paths.
They inform consistency and path interpretation; no third-party artwork copied.
